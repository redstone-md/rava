**rava v0.0.2-alpha: crash diagnostics on Windows, a hashing race fixed, faster calls.**

`alpha` · Linux, macOS and Windows on x86-64 · Java 21 class library · drop-in `java`

> [!WARNING]
> An alpha: expect crashes and differences from HotSpot, and keep backups of any world you open
> with it. Reports are welcome in [Issues](https://github.com/redstone-md/rava/issues).

## 🐛 Fixes

- **Crash reports on Windows.** A memory fault in rava's own code is reported on stderr at once
  (faulting instruction, module, native and Java frames). Before, the report waited for the
  unhandled-exception filter, which libraries a game client loads replace, so a crash left only
  the exit code `-1073741819`. Please attach this report to crash issues.
- **Identity hash race.** `hashCode()` of an object being locked by another thread at the same
  moment could return 0 once and a different value afterwards, so a `HashMap` could lose keys.

## ⚡ Performance

- Register arguments on virtual and interface calls, and argument registers chosen with the
  calling convention in mind.
- Early returns run before the method's prologue (a recursion's base case, a cached value).
- Global value numbering; loop-invariant arithmetic on constants leaves loops; constant
  arithmetic folded after loops are fully unrolled.
- Values rarely read are no longer saved and restored around every call they live across.
