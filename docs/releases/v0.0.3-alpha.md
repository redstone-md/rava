**rava v0.0.3-alpha: diagnostics for crashes in native libraries on Windows.**

`alpha` · Linux, macOS and Windows on x86-64 · Java 21 class library · drop-in `java`

> [!WARNING]
> An alpha: expect crashes and differences from HotSpot, and keep backups of any world you open
> with it. Reports are welcome in [Issues](https://github.com/redstone-md/rava/issues).

## 🐛 Diagnostics

- **Crash reports for faults in native libraries on Windows.** Libraries a game client loads
  (drivers, audio) replace the process's unhandled-exception filter, so a crash inside them ended
  with only the exit code `-1073741819`. rava now takes the filter back once a second and
  reports first (`rava: memory fault at pc … module+offset`, native and Java frames), then
  passes the crash on.
- **`RAVA_OPT_EXCLUDE=<prefixes>`** keeps methods whose `package/Class.method` starts with one of
  the comma-separated prefixes out of the optimizing tier, compiled and inlined alike (HotSpot's
  `CompileCommand=exclude`). If a program works with `RAVA_OPT=0` and fails without it, halving
  with this finds the miscompiled method
  ([troubleshooting](https://github.com/redstone-md/rava/blob/main/docs/troubleshooting.md)).
