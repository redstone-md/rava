# The phase map, and the last axis coming back flat

*2026-08-26*

Every other slicing of this boot came back flat, so this one cuts it by PHASE — a different axis
from functions, categories and callees, and the one where a concentration could still hide.

## Where the boot actually goes

| phase | rava | java | ratio |
|---|---|---|---|
| start → `Environment:` | **26 s** | ~4 s | 6.5x |
| **`Environment:` → `Loaded 1470 recipes`** | **21 s** | **2 s** | **10.5x** |
| recipes → `Done` | ~1 s | ~0 s | — |

(java's log begins AT `Environment:`; its pre-log window is the difference between its 6.3 s wall
and the 2 s it logs.)

So the datapack/registry phase is **44% of our boot and our worst ratio.** That is a real
concentration on the phase axis — the first one this session.

## And its profile is flat too

Profiled with `RAVA_PROFILE_PC_MS=8000` so a dump lands inside the phase rather than only in the
first 30 s:

```
4.8% opcodes::invoke_virtual   4.7% memchr        4.7% mi_malloc_aligned
3.5% drop_in_place<Option<Value>>                 1.8% natives::try_invoke_chain
1.8% NtCreateFile              1.7% invoke_idx    1.7% invokedynamic
1.7% ZwReadFile                1.5% jit_fu_invoke 1.4% jit_direct_call
```

Top row 4.8%. The same shape as the whole-boot profile, the category map, and the seam census.

The one thing this phase has that the others do not: **`NtCreateFile` 1.8% + `ZwReadFile` 1.7%
= 3.5% in file syscalls**, which is MC reading thousands of small JSON resources. Above the floor
and specific, but it is 3.5%, not the 10.5x.

## What the five axes now say together

| axis | largest single item |
|---|---|
| host function | `drop_in_place<Option<Value>>` **4.3%** — deleting it entirely measured -2.10% |
| category | JIT+seam **11.4%** |
| seam callee | `List.get` **10.37%** of a ~14% seam — inlining it measured +1.68% / +3.90% |
| phase | datapack load **44%**, and its own profile tops out at **4.8%** |
| configuration | the JIT itself, **3x** — but both directions off the default collapse |

Five different ways of cutting the same 40 seconds, and the only thing worth more than ~11% is
having the JIT at all. There is no address left to fix; the cost is the shape of the engine.
