## What this changes about method

⭐**A 10-second probe that reproduces the shape resolves what a 35-second boot cannot.** The
iterator intrinsic reads −17% on `bench/StreamApplyCost.java` and −3.8% on the boot, and only one
of those two numbers is above its instrument's floor. The probe found it; the boot could only
just confirm it.

⚠And the probe has its own limit, measured the same day: it reproduces the SHAPE but not the
receiver DISTRIBUTION, so it decides per-operation cost and never admission policy
(`docs/coverage-is-not-the-threshold.md` and the `fu_routable` comments carry that case).

⇒ The working rule for the next session: **counts first, probe second, boot last** — and never
quote a boot delta under 3% without a null test taken the same hour.
